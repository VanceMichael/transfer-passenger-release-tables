# 数据字典

合成记录采用 UTF-8 JSON 数组。主键和字段名称见 `manifest.json`。空值为来源未提供。

旅客凭证为单航段匿名标记，不能跨航段自行比对。transfer 旅程按链接入港日与入港航段市场、时段和承运人归属；through 同样按入港归属，其余未确认的中转可能性仅出内部缺口。市场可查看源市场及当期公开大类。精确数按整数计算；公开可逆同比指公布的精度和同发布范围的历史量能共同唯一确定格。政策只保护 1 到 minimum_cell 之间的格，不含 minimum_cell；缺未走出无法区分的未知客群可用区间，不签发为确定计数。已发布计数属于当时资料版本，已知修订可以把新、旧口径同一群体的上下界联系起来。

- `movement.json`　旅客联检系统的匿名单次航段过站观测。
- `boarding.json`　对应的通行凭证，保留原机标志。
- `link.json`　联程确认边，kind 为 transfer、through 或 unknown。
- `markets.json`　源市场分类及有效日期。
- `policy.json`　媒体发布允许的维度、替代粒度优先级及对精确零格的口径。
- `publications.json`　外界已收到的精确格，包含曾发布后被新版替代的内容。
- `requests.json`　发布申请可与去年同期间比较，先由编辑保留候选表。
